# AnchorFlow V11.3 Viewer

Frontend production độc lập: 10 ảnh, depth timeline, coarse/fine jet 3D, pixel selection và before/after wipe.

Import GitHub repo vào Vercel, chọn **Root Directory**:

```text
visualizations/AnchorFlow_V11_3_Vercel
```

Framework **Other** · Node **22.x** · Build `npm run build` · Output `dist` · không cần biến môi trường.

Local: `npm run dev`. Kiểm tra: `npm test`.

Xem [hướng dẫn deploy và dữ liệu hiển thị](README_DEPLOY.md). Giữ nguyên folder `site/` gồm tất cả recorded assets; không upload dataset/checkpoint.
